# Public Release Checklist

Use this checklist before pushing code or assets to the public repository.

## Safety checks

- [ ] No environment files
- [ ] No private credentials
- [ ] No private automation exports
- [ ] No client data
- [ ] No database exports
- [ ] No private server details
- [ ] No paid production prompt library
- [ ] No third-party assets without permission

## Repository checks

- [ ] README explains the product clearly
- [ ] LICENSE.md is included
- [ ] .gitignore is included
- [ ] Screenshots are added in docs/screenshots
- [ ] Demo runs locally
- [ ] Links are not broken
- [ ] Mobile layout is tested
- [ ] EN/FR text is reviewed

## Product checks

- [ ] Hero message is clear in 5 seconds
- [ ] CTA is visible above the fold
- [ ] Avatar worlds are easy to understand
- [ ] Audit flow is clear
- [ ] Public demo does not expose private business logic
